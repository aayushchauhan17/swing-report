# swing-report

**→ [aayushchauhan17.github.io/swing-report](https://aayushchauhan17.github.io/swing-report/)**

A published page of weekly swing-momentum signals for NSE (India), regenerated by
a scheduled GitHub Actions job. This repository holds **only the rendered page**.
The engine that produces it, and the account it is traded with, are private.

## What is on the page

Symbols, their rank in the universe, the last close, the stop-loss **price
level**, how far below the close that stop sits, and a news/corporate-event flag.
Plus, for each buy, why it was selected — momentum, volatility, rank and
turnover, all computed from NSE's public end-of-day archive.

## What is deliberately not on the page

Position sizes, share quantities, account value, cash, rupees at risk, and
profit or loss. The renderer that builds this page is an **allowlist** — it emits
only fields it has been told to emit, so a new field added upstream cannot appear
here by accident. A test asserts those absences on every push.

## Read this before you use it

- **Not investment advice.** Nothing here predicts a price. The ranking is a
  comparison of one public price series against every other liquid stock on the
  exchange, on the day it ran.
- **A stop that exists only on this page is not a stop.** Nothing here watches
  the market intraday. To be real, a stop must rest with a broker as a GTT order
  — and even then, a price can gap straight past it overnight.
- **The list is generated weekly, not daily.** The underlying system rebalances
  every five sessions and uses a buffer band specifically to avoid trading the
  day-to-day churn in the ranking. Acting on every small change in the order
  would cost more in charges than the ranking is worth.
- **Backtested results are an optimistic ceiling, not a forecast**, because the
  same history was used to design the system.
- The page is `noindex` — it is meant to be bookmarked, not found in a search.

## Provenance

Data: NSE's public end-of-day archive (bhavcopy), no paid feed, no API key.
History is survivorship-bias-free — delisted names are retained, so the ranking
is not flattered by only knowing about the companies that survived.
